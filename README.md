# steel programm
## Руководство пользователя: Цифровая библиотека

### 1. Назначение программы
Приложение предназначено для работы с электронной библиотекой: позволяет регистрироваться, просматривать каталог, брать и возвращать книги, оставлять отзывы и оценки. Для библиотекаря предусмотрены функции управления каталогом и пользователями.

### 2. Требования
- Установленное приложение (Windows/Linux).
- Доступ к базе данных (MySQL, PostgreSQL или SQLite).
- Для библиотекаря — отдельный вход с правами администратора.

### 3. Начало работы
- Запустите приложение.
- На главном экране выберите «Регистрация» (для новых пользователей) или «Вход» (для существующих).

### 4. Регистрация читателя
1. Введите ФИО, логин, пароль и номер читательского билета.
2. Нажмите «Зарегистрироваться».
3. После успешной регистрации войдите в систему, используя логин и пароль.

### 5. Вход в систему
1. Введите логин и пароль.
2. Нажмите «Войти».
3. Откроется главное меню.

### 6. Работа с каталогом
- Используйте фильтры (жанр, автор, год, наличие) для поиска книг.
- Для оформления заявки на книгу выберите нужную книгу и нажмите «Взять книгу».
- Если книга занята, можно встать в очередь.
- Для возврата книги выберите её в разделе «Мои книги» и нажмите «Вернуть».

### 7. Оценка и отзывы
- После прочтения книги можно оставить оценку (1–5) и отзыв.

### 8. Раздел «Рекомендации»
- В этом разделе отображаются топ-5 самых читаемых книг.

### 9. Выход из системы
- Нажмите «Выход» в главном меню.
